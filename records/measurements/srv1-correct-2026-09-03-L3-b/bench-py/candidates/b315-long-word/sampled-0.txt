```python
def long_word(sentence: str) -> str:
    """
    Return the longest word of a sentence, where any run of spaces separates two words.
    When two words are equally long the one appearing first wins, and a sentence holding no words at all gives back empty text.
    """
    if not sentence:
        return ""
    
    words = sentence.split()
    if not words:
        return ""
    
    longest_word = max(words, key=len)
    
    return longest_word
```
