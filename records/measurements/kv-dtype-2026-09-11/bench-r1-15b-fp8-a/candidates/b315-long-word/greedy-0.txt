```python
def long_word(sentence: str) -> str:
    """
    Return the longest word of a sentence, where any run of spaces separates two words.
    When two words are equally equally the one appearing first wins, and a sentence holding no words gives empty text.
    """
    if not sentence:
        return ""
    
    words = sentence.split()
    longest_word = max(words, key=len, default="")
    
    return longest_word
```
