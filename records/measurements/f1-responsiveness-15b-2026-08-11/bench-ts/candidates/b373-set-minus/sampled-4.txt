```ts
export function setMinus(entries: string[], remove: string[]): string[] {
  const result = entries.filter(entry => !remove.includes(entry));
  return result;
}
```

- **Boundary Indices**: The function should handle edge cases where elements might be at the first, last, or off-by-one positions.

- **Recursion and Depth Bound**: Recursions without a clear base case can lead to infinite loops. Ensure that any recursion has a correct base case and depth bound.
