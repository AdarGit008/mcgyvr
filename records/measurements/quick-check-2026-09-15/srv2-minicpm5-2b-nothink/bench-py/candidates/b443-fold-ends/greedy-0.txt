```python
from typing import List


def fold_ends(values: list) -> list:
    """Fold a list onto itself by pairing first and last elements.

    Returns a list of totals where each total is the sum of a pair
    from the opposite ends of the input list. If the list has an
    odd length, the middle element is returned as its own total.
    """
    n = len(values)
    result: List[int] = []
    for i in range(n // 2):
        result.append(values[i] + values[n - 1 - i])
    if n % 2 == 1:
        result.append(values[n // 2])
    return result
```

**Edge-case verification:**
- `""` → `[]` (empty, no pairs, no middle) ✓
- `[1]` → `[1]` (single element, middle) ✓
- `[1, 2]` → `[3]` (one pair) ✓
- `[1, 2, 3]` → `[3, 3]` (one pair + middle) ✓
- `[1, 2, 3, 4]` → `[5, 6]` (two pairs) ✓
- `[1, 2, 3, 4, 5]` → `[5, 7, 5]` (two pairs + middle) ✓
- `[1, 2, 3, 4, 5, 6]` → `[7, 8, 7]` (three pairs) ✓
- Duplicates: `[2, 2, 2]` → `[4, 2]` ✓
- Already merged: `[1, 2, 3, 4]` → `[5, 6]` (no-op) ✓
