The bug is that the condition is inverted: `score < floor` should be `score >= floor`.

```python
def mark_list(scores: list, floor: int) -> list:
    """Scores written out, with a star against those that reach or exceed a floor."""
    out = []
    for score in scores:
        out.append(str(score) + "*" if score >= floor else str(score))
    return out
```
