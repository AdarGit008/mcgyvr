```python
def mark_list(scores: list, floor: int) -> list:
    """Scores written out, with a star against those that reach a floor."""
    out = []
    for score in scores:
        out.append(str(score) + "*" if score == floor else str(score))
    return out
```

The bug was a comparison operator: the original code used `score < floor` (marking entries *below* the floor), but the task requires marking entries that *reach* the floor, i.e., entries equal to the floor. Changed `<` to `==`.
