## The constants, one line each

- **`RAMP_LEVELS`** — the sentence "the top is above any plausible width" was
  false: maxima sit at 128 (srv1) / 256 (srv2). New **`ladder(width)`**
  continues the knee ladder through `RAMP_LADDER_EXTENSION` (32…384) to one
  level past 1.5× the configured width; width ≤ 16 — every D7 row — gets the
  old ladder unchanged. `calibrate.py --phase ramp` uses it. Cost stated: ~1 h
  per two-repeat ramp at width 256 on srv1, ~10 min on srv2. The survey
  default stays the knee ladder: ollama reports `total_slots = 1` and a level
  of 24 already costs 6-9 min on the deep-spill models.
- **`RAMP_TOKENS = 475`** — survives. At n=1, 475 reads 97% / 95% of the
  1024-token rate; 128 reads 81% / 77%. **The per-request overhead is not
  fixed in seconds** — 0.79 s srv1, 0.22 s srv2 — so its share at 475 is
  6.9% / 8.3% on both rigs. D3's argument was about a share, and the share
  survived the rate being corrected. Past the knee 1024 reads 6-10% BELOW
  475: longer is a different regime.
- **`PLATEAU_FRACTION = 0.92`** — 0.92 and 0.95 agree on all 104 cells; 0.90
  differs on two. At powers-of-two resolution.
- **`INFERRED_SATURATION_MIN_SPEEDUP = 1.0`** — lowest graphs-on speedup 3.61;
  nothing within 3× of the floor. The 0.02 boundary case is a width-1 property.
- **`RAMP_FLOOR_TOKENS_PER_S` / `RAMP_TIMEOUT_BASE_S`** — slowest request used
  14.9% of its budget across 104 cells and a ladder to 384. The floor is
  aggregate: srv1 ran 0.79 tok/s per stream at n=256 against a 30,490 s budget.
- **`RAMP_REPEATS = 2`** — reads no rate. The only spread on record is eager

## The rule that lands

**`contract.PROVENANCE`**: every numeric constant in `contract.py` names the
evidence directory it was derived from or re-read against, a date, a kind
(`derived` | `invariant`) and a note.
`tests/test_serving.py::test_every_serving_constant_names_the_run_behind_it`
refuses a constant with no entry, an entry naming no evidence directory with a
README on disk, and an entry naming no constant; a second test shows all three
rejections. The gap #356 named — a number pinned by a marker while the run
behind it is void — is now a failing test rather than a sentence.

Markers: no constant's value moved, so no marker string changed; three added
(`def ladder(`, `PROVENANCE: dict[...]`, `contract.ladder(width)`).
`launch.check()` reports no problems.
