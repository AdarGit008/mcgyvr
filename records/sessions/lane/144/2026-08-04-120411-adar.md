# Session — lane/144 — 2026-08-04

## Did
Made the sweep runnable against a worker that is not on this machine, and found
that the command this repository has been documenting could never have worked.

**The worker is configuration now.** `tools/bundle/worker.local.json`,
git-ignored, holds the endpoint, protocol, model and the *name* of the variable
holding a key; `worker.example.json` is the committed shape. Flags beat the
file. An endpoint is a fact about somebody's infrastructure — a hostname, a
tunnel port — and it was previously only expressible as a command line that had
to be retyped correctly on every invocation.

**The rig could not use a keyed endpoint at all.** `credential_env=None` was
hardcoded at the one place an `Endpoint` is built, so every remote worth
reaching — a hosted provider, a box behind a gateway — was unreachable while
`pool` and `runner` had supported credentials all along. Now `--api-key-env`,
and the name is all that is ever written down: a key *value* in the worker file
is refused by name, because git-ignored is not encrypted.

## Found

**`--protocol ollama` cannot carry this measurement, and every document here
said to use it.** The rig marks every request `quality_sensitive=True` — its
output *is* a measurement of the model — and `runner.generate` refuses such a
request on a caveated path before sending it. Ollama's native `/api/generate` is
caveated under CAV-01, which measured it scoring a model at 32.3% against a true
84.1%. So the command in `measure.py`'s docstring, in the rig README, in the PR
and in session/1's "Left" would have produced **eighty dispatch errors and no
measurement**, arriving one request at a time and phrased as a transport
problem.

Nothing caught this because nothing had dispatched. The fix is a different
protocol on the same endpoint — Ollama serves `/v1/chat/completions` on the same
port — and it is now refused up front, while it is still a typo, rather than
after a night of it. This is the second time in two sessions that the defect was
a check standing next to the thing it was meant to check: the Node guard asked
whether Node existed, and this asked nothing at all.

**Rows no longer imply their backend.** While the worker was a localhost
constant, "which model, on what stack" was ambient. Once it can be anything
anyone can reach, a rate without its provenance is not quotable — CAV-02 is
exactly that a figure from another backend describes different weights. A sweep
writes `run.json`: endpoint with embedded credentials stripped, protocol, model,
a SHA-256 per condition, the rig's revision, one entry per invocation. Resuming
into a directory whose manifest names a different worker or ladder is refused,
because the resume path plus a changed `--model` silently averages two
measurements into one table — and the table is the whole output.
