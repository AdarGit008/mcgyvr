# Measured serving grid, 2026-08-30/31

`agg` is aggregate throughput (`tokens_per_s`, run.py's key -- sweep.py calls
the same quantity `agg_tok_s`). `per-stream` is `agg / n`, exact.
`key` is `agg x total_params`, per the run request.

**Params are sourced only from the model's own identifier or its GGUF
`general.size_label`.** The repo declares parameter counts nowhere, so where
a MoE's total is not stated by the file it is left blank rather than guessed --
and `key` is not computed for those rows.
