Settled the orch naming question that had been open three sessions (#87, ADR-0003). Owner's call: a binding's role is derived from where it sits in the schema, so the role token is deleted rather than relocated. The reasoning that makes it a deletion — the only named things are ladder tiers and every tier is a worker, so a role token is constant across every name that exists. Convention becomes <locality>_<model>, tiers only. Rejected a bindings: section — it de-duplicates one source and one model string and charges every reader of a hand-edited policy file a lookup; ADR-0001 chose YAML for hand-editability. Both rejected forks are in ADR-0003 because I proposed the second one myself twice before seeing why it was wrong.
