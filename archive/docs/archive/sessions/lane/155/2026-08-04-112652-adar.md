**The issue's own premise about which types need content is false in the
running system, and that is what made "no type list" the answer.** #155 argued
the deterministic tier never needs the file because a tool reads it. But the
tier is not what decides whether a tool runs the contract: `escalate.ascent`
climbs from the contract's floor family upward, and the deterministic family
binds no rung at all (`route._why_empty` — it is tools, and #81 is unbuilt), so
a `format` contract reaches a model rung today exactly as a `bug_fix` does.
Content a tool ignores costs nothing, because that tier builds no prompt to
carry it. So there is no catalog key and no branch: fill the slot when there is
exactly one file it could be the content of, which is the rule the loader
already states from the other side.

**The bytes come from the index.** It is the state resolution and exploration
already judged from, so two contracts of one run cannot disagree about one
file, and no second unbounded read appears inside a step whose cost model is
that the index was built once. Exact, not approximate: `index_source` splits a
`surrogateescape` decode on newlines and joining on the same separator inverts
it. `Proposal` gained no field and will not — a proposer that could state a
file's content could state one the repository does not hold, which is what
ADR-0007's seam exists to prevent.

**A target too large to send is refused, and the argument is the output
protocol rather than strictness.** With `whole_file` the reply *is* the file's
complete new content, so a target too large to send is too large to receive
back; the contract is undispatchable in both directions. The refusal names the
measured size, the target's own share of it, and #126.

**The ceiling had to exist or the fit check becomes a tautology.** `_resize`
sizes `max_input_tokens` off `worker_view()`; with the content inside that view,
a budget derived from it can never be exceeded by it. `check_prompt_fits` would
be asking whether a number exceeds itself.

## Found

**Nothing in mcgyvr declares what a rung can actually accept.** The ceiling is a
chosen number (32 768) and says so in the source, because there is nothing to
derive it from: the config binds sources and attempts, and the capability table
carries quality, throughput, VRAM and quant with per-measurement provenance —
and no context window. The same absence is already papered over one layer down:
`build_prompt` passes the *contract's* declared budget to `check_prompt_fits` as
the `context_window`, because there is no model window to pass. One missing fact,
filled with a placeholder twice. Filed as **#158**.

**The delegated path cannot emit a contract that creates a file.** `_indexed`
refuses any target the index does not hold, which is right for a typo and wrong
for a file that does not exist yet — the two are indistinguishable to it. So
`function_implementation` on a new module and `test_scaffold` on an unwritten
test file are direct-mode-only shapes, and the schema's "empty means the target
does not exist yet" is unreachable from here. Held by a test that asserts the
refusal rather than by a comment, and filed as **#159**. Not fixed: what
separates an intended new file from a mistyped one is a real question, and
answering it inside a schema-filling change would have been the same overreach
#150 declined.

**A test that cannot fail on the mutation it exists to catch.** The "no type
list" claim was first asserted with a `docstring` proposal — but docstring is
model-tier, so a mutation withholding content from deterministic types survived
it. Parametrised over `format`, which is the case the issue expected to be
excluded and the only one that can catch it.
