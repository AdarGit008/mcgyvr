**93.8% of the admitted bench is already language-idempotent, and nothing that is not is fatal.** `idempotency.py` points `emit.py`'s divergence screen backwards — at the 257 problems that passed the gate rather than forwards at a candidate. 241 clean, 16 flagged, **0 fatal**, over seven rules: the `.isalpha`-family (5), a remainder passed a negative (5), `localeCompare` (2), a bare `.sort()` on a numeric receiver (3), `Math.trunc` (1). The screen is a fixed pattern table holding the divergences this project has been burned by, so a construct nobody has been burned by yet passes it silently; the module says so where the number is produced rather than in a record beside it.

**The second arm looked indispensable and then turned out to be measuring the bar.** `arms.py` joins each recorded run's two arms cell by cell. Read naively the arms barely agree: of the cells solved at all, only 17–47% are solved on both, with phi between 0.006 and 0.49 — against a within-arm reproducibility of `d = 0` of 514, where identical re-runs flip nothing. That reads as an enormous language effect.

It is not one. `rejected_by` splits the failures by rung, and the two arms fail at different rungs entirely:

```
bench-null-gate-15b-a   py: lint 153, acceptance 56, format 23
                        ts: format 124, acceptance 66, lint 32
bench-null-gate-7b-a    py: lint 128, acceptance 33, format 29
                        ts: format 159, acceptance 28, lint 17
```

Python dies at ruff and TypeScript dies at prettier, while the **acceptance-stage** failures are nearly identical across arms — 56 against 66, 33 against 28, 29 against 29. Drop the cells either arm lost at lint or format and concordance moves 31.1% → **75.7%** on the 7B gate run and 32.2% → **80.6%** on the 7B control. Most of the apparent language signal is #262's unrecorded bar, measured. Cross-posted there, because it is that issue's premise confirmed and it should not sit only in this lane.

Two limits travel with that read and are in the module rather than only here: `rejected_by` names the first rung and not every rung that fired (#257), so the filter is approximate in the direction of *under*-counting acceptance failures; and the 15B gate run leaves 52 cells after filtering, which is too few to read. The pre-gate run of 2026-08-12 is the control on the whole argument — it was scored by the acceptance command alone, has no lint or format rungs at all, and its concordance is identical before and after the filter at 44.0%.

**Pooling is refused in both tools.** Runs differ by model, condition and bar, and #263 already records a confirmed pooling defect here. Every row is its own run; the totals line counts rows.

**The tests pin the arithmetic, not the corpus.** Phi against the 2×2 formula worked by hand, McNemar against an explicit enumeration of the coin flips it abbreviates, the concordance against the case it exists to separate — a table agreeing on 95% of cells where 190 of 200 agreements are mutual failure. The census's own count is deliberately **not** asserted: it moves whenever a problem is authored or retired, and freezing it would be a test of the corpus's size wearing the costume of a test of the module.

**One correction carried in from lane/268.** The first reading of "`bench-ts` yields 7 families where `bench-py` yields 8" was that `b430`'s TypeScript acceptance is stronger. A per-arm family count measures python's duck typing, not the material.
