- The reconcile cron (tools/baseline/src/reconcile.mjs, OPS-07) is a ready-made forge-side home for issue-body and dependency-graph re-checks: read-only against the repo, writes findings to the issue tracker with a full dedup lifecycle keyed baseline:<id>:<subject>, cap of 10 creations/reopens per run. New forge-side checks should be reconcile finding sources, not new CI jobs.
- CTX-10 'path-integrity' (warn) already does for committed docs a weak version of what vector (a) needs for issue bodies: backticked path tokens must exist as files (evaluators.mjs, path-integrity branch). It checks existence only — no line numbers, no symbol resolution, and never issue bodies.
- Baseline severities are static in tools/baseline/rules/*.json with no config override mechanism (engine.mjs:58); promoting a warn to blocker is a one-word edit to the vendored rule file, which REC-06 pins — so severity promotions must go through the vendored-tree update path.
- tools/issues/body.py verify exists but is invoked by nothing: no committed bodies/ mirror, no Makefile or CI reference. As shipped it is a hand tool, not a drift check.
- pytest runs in CI twice: as the test job and inside the baseline gate via BUILD-05's bootstrap_command ('uv sync --frozen && uv run pytest -q', baseline.config.json), so a new pytest check is automatically both a CI failure and a baseline FAIL.
- The docgen idiom already solves 'derived index' for (f): docs/config-reference.md is generated from SCHEMA by make docs, listed in generated_globs (CTX-08 marker), and make docs-check fails on drift — a generated docs/decisions/INDEX.md can reuse the whole path, and a hand-maintained index would contradict CTX-12's own doctrine.
- The (c) incident's exact mechanism: 'short of 5pp' compared against a threshold appearing nowhere in the document's own tables (the psi table reads 5.5/4.5/3.8pp) — which is what makes it machine-flaggable, unlike a wrong-but-cited figure.
- The lane/266 record states the limit of all repo checks for vector (c) explicitly: 'The escalation from we-did-not-find to nobody-has-measured happened between a document and a sentence spoken about it... nothing in the tooling would ever have caught it.' Any plan should quote this as the declared residual risk, not promise to close it.
