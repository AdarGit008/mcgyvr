Working through what that measurement could report exposed the deferral's defect: yield-over-declared-checks is observable only where declared checks exist, and the strongest case for the rung is repositories that declare none. The sampling frame excluded the population carrying the effect.

The rule binds task types; it does not bind lines or repositories.
