### Q: Does `uv run --no-sync python tools/power/report.py --section contrasts` reproduce the corrected figures (nine structurally unresolvable, zero of twelve rejected, min p=0.070) rather than 'eleven of twelve'?
VERDICT: CONFIRMED
EVIDENCE: Ran `uv run --no-sync python tools/power/report.py --section contrasts` at main 4e110156: the 12 bundle rows (4 matrices x 3 contrasts, all n=20) show exactly 9 rows flagged 'NO — m<6' (m = 2,5,4,2,5,1,1,1,4) and 3 resolvable 'yes' rows: bundle JS/TS srv2 c0->c3 (m=6, p=1.000), Python arm B c0->c1 (m=7, p=0.453), arm B c0->c3 (m=8, p=0.070). Zero of twelve reject at .05; minimum p = 0.070 (arm B c0->c3, 7 gained/1 lost). Independently recomputed from the raw gain/loss counts with mde.exact_p: 9 unresolvable, 0 rejected, min p 0.0703125. Hand check: m=8, min(b,c)=1 gives 2*(1+8)/2^8 = 18/256 = 0.0703. 'Eleven of the twelve' is refuted by the tool ADR-0020 itself names as the check.

### Q: Does tools/power/mde.py arithmetic hold at n=20 across the psi range the records show — i.e. does 'at n=20 no effect size reaches 80% power across the measured discordance range' survive?
VERDICT: CORRECTED — true for every measured psi except the single boundary point psi=0.40, where only a +40pp unanimous effect is detectable; the claim survives for every effect size any bar discusses
EVIDENCE: Measured per-contrast psi range is 0.05–0.40 (m=1..8 over n=20, from the live contrasts table). detectable_delta(20, psi) is None for all psi in 0.01..0.39; at psi=0.40 it returns 0.40 (exact_power(20, 0.40, 0.40)=0.874), i.e. detection requires all 8 discordant pairs to flip the same direction (+8 tasks = +40pp). At psi=0.35 the max-possible-effect power is 0.755 < 0.80. The wall table report.py prints (`--section wall`) shows psi 0.10/0.20/0.35 all 'unreachable' at n=20 and never prints psi=0.40, so the ADR's cited table displays no exception. The observed psi=0.40 contrast was 7/1, not 8/0 (p=0.070). MIN_DISCORDANT=6 wall arithmetic checks: m=5 best case 2/32=0.0625>.05, m=6 best case 2/64=0.031<.05.
